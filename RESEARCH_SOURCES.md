### Page audio source research and decision

- **Browser API:** [MDN AudioContext](https://developer.mozilla.org/en-US/docs/Web/API/AudioContext), [Web Audio API best practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices), and [Using the Web Audio API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Using_Web_Audio_API). The docs describe an audio-node graph, context reuse, user-gesture resume, audio buffers, filters and gain scheduling. MDN content is reference documentation, not a bundled sound asset.
- **Alternative:** a prerecorded foley WAV/MP3 would need an appropriately licensed sound file, an extra public asset, and a user-gesture-safe playback path. No paper sound asset was supplied; using a downloaded sound would add provenance/asset requirements.
- **Selected:** synthesize a short, low-volume paper-rustle from a locally generated noise buffer through Web Audio nodes, only at the start of a user-driven page turn and only when the global sound preference is on. No microphone, network call, external audio file, or copied sound code. Reuse one `AudioContext`; suspend it when sound is off; disconnect transient nodes and close on unmount. Browsers that block or lack Web Audio keep the page controls usable and simply stay silent.

### Chosen cake implementation plan

- Keep the existing birthday section, illustrated cake, name/date, accessible controls and no-microphone policy.
- Add a clearly labelled **Bake the cake** sequence: ingredients arrive; batter pours into a pan; the pan enters the oven; the door closes and warm interior light appears; cake rises and changes from batter to baked color; the door opens and the cake is presented with layers/cream/frosting decoration. The exact motion is illustrative, not a kitchen simulation.
- Keep a distinct assembled cake illustration with visible sponge/filling/frosting and decorative piping; preserve the existing five candles and one-by-one ignition.
- On “Make a wish,” extinguish candles in a controlled sequence, reveal a short smoke wisp at each wick, then play a bounded confetti/balloon/fireworks accent and reveal the supplied birthday message. Keep a separate blow-out control for the no-wish path and provide replay/reset.
- Use one scoped timeline and kill it on replay/unmount. In `prefers-reduced-motion`, skip the journey and expose a complete final illustration/message; do not leave controls in a busy/disabled state.

## 3. Motion, handwriting and future scene research references

These sources inform the planned follow-on chapters but are **not evidence that every listed effect has been implemented**. Any later source reused in shipped code must be re-evaluated for license and documented here.

- **Coordinated timeline / cleanup:** [GSAP Timeline docs](https://gsap.com/docs/v3/GSAP/Timeline/) explain sequence labels, overlapping positions and play/reverse/seek controls. The current project already uses GSAP/ScrollTrigger; avoid adding another animation framework. Do not use paid GSAP plugins unless a separate license is approved.
- **Native SVG ink reveal:** [MDN `stroke-dasharray`](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/stroke-dasharray) and [MDN SVG fills/strokes tutorial](https://developer.mozilla.org/en-US/docs/Web/SVG/Tutorial/Fills_and_Strokes) document stroke dashing/offset. A future handwriting flourish can animate project-authored paths with native SVG/CSS, but must not generate or alter the supplied letter copy.
- **3D CSS / postcard fallback:** [MDN perspective](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/perspective) and [CSS transforms tutorial](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_transforms/Using_CSS_transforms) cover perspective, transform style, origins and faces. Prefer a simple two-face CSS postcard over WebGL if only a card flip is needed; do not use it as a substitute for the scrapbook’s bendable leaves.
- **Reduced motion / finite motion:** [MDN CSS performance](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Performance/CSS) and the platform `prefers-reduced-motion` media query inform the static/reduced state. Existing scene/chapter styles already contain reduced-motion handling; additions must follow it.
- **CodePen:** CodePen was searched for book curl and cake/oven animation examples. The inspected demos did not expose a clear, compatible reuse license; they are not redistributed or copied. Any future Pen-specific reuse requires an explicit license check first.
